# Rede Raízes do Nordeste - Interface Front-End

Projeto da disciplina Projeto Multidisciplinar - Trilha Front-End (UNINTER 2026).

## O que é

Interface simples para pedidos de uma rede de lanchonetes.
Funciona em App (mobile), Totem e Web.
Usa dados mockados (não tem backend real).

## Como rodar

1. Baixe os arquivos
2. Abra o `index.html` no navegador (Chrome, Firefox, Edge etc.)
3. Pronto

Não precisa instalar nada.

## O que tem no sistema

- Escolha de unidade (cardápio muda)
- Cardápio com produtos
- Carrinho
- Login e cadastro (com aceite de LGPD)
- Programa de fidelidade (pontos)
- Pagamento simulado (externo)
- Acompanhamento de status do pedido
- Banner e política de privacidade (LGPD)

## Tecnologias

- HTML
- CSS (mobile-first)
- JavaScript puro
