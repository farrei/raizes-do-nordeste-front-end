**Aluno:** Rafael Ferreira Verissimo

## Sobre

Interface para pedidos de uma rede de lanchonetes nordestinas.  
Funciona em App (mobile), Totem e Web.  
Dados mockados (sem backend real).

## Como rodar

Abra o arquivo `index.html` no navegador.  
Não precisa instalar nada.

## Funcionalidades

- Escolha de unidade (cardápio dinâmico)
- Cardápio com imagens
- Carrinho de pedidos
- Login e cadastro com aceite LGPD
- Programa de fidelidade
- Pagamento simulado (serviço externo)
- Acompanhamento de status
- Efeito visual de fumaça leve
- Layout responsivo (mobile-first)

## Tecnologias

- HTML5
- CSS3
- JavaScript (vanilla)
